# Money Implementation Plan (Phase 2 of 5)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Money becomes its own state class, `Finances` (cash, debt, a credit line), and every open building costs upkeep, charged each month together with interest. A bill the cash can't cover borrows automatically, plus a fee.

**Architecture:**
- `Finances` (new, `src/state/`) is the only writer of `cash` and `debt`.
- `Campus` loses its `money` and spends from a `Finances` it's given.
- `University` owns both and makes them together, so the campus always spends from the university's finances, including after a load.
- `University.startMonth` opens what's due, then charges the month's bill: `Campus.upkeep()` + `Finances.interest()`.
- Upkeep comes from a new Sheet column, `upkeepK`, converted once in `BuildingInfo`.
- The save format moves money from `campus` to `university.finances`.

**Tech Stack:** Godot 4.7, fully typed GDScript, gdUnit4, LimboConsole + TCP remote console, Python 3 sheet export.

**Spec:** `docs/superpowers/specs/2026-09-22-students-money-hud-design.md`: **Phases → 2**, **State → `Finances`** and **`Campus`**, and the **Data** table's `upkeepK` row. Read the spec and `CLAUDE.md` before any task.

## Global Constraints

- **Paths.** Repo root `/Users/noel/Development/University/game`; Godot project `university/`. `res://` is `university/`.
- **`CLAUDE.md` governs:**
  - camelCase variables and functions; PascalCase classes, constants and signals
  - `if (x):`
  - fully typed GDScript, where unsafe access **and shadowing** are errors
  - no magic numbers (named `const`)
  - TAB indentation
  - no duplicate logic, surgical changes
- **No shadowing.** `project.godot` escalates `shadowed_variable`, so a local or parameter named like a member of its class, including in a static function, fails to parse. Name loaded parts `loadedX`, and constructor parameters something other than the member (for example `fundedBy`).
- **State classes** (`src/state/`, `src/data/`) are plain `class_name` classes: no Node, no Input, no scene tree, no file I/O, no views.
- **A Variant from a Dictionary or Array** never goes into `int()`, `float()`, `bool()` or a typed parameter. Use `Variants.toInt` / `toFloat` / `toBool`, `str()`, or `as Dictionary` / `as Array`.
- **Exact values from the spec:**
  - `Finances.CreditLimit` = 50000000 (whole dollars)
  - `AnnualInterestRate` = 0.06, with `MonthlyInterestRate` = `AnnualInterestRate / GameCalendar.MonthsPerYear` derived next to it
  - `ShortfallFee` = 0.05 (fraction of the shortfall)
  - `LoanStep` = 5000000
  - cash and debt are whole dollars and never negative
  - building spends cash only
  - `borrow` takes `min(amount, CreditLimit − debt)` and returns it
  - `repay` pays `min(amount, debt, cash)` and returns it
  - **`charge`:** paid from cash if it covers the bill. Otherwise cash goes to 0 and `debt += shortfall + roundi(shortfall × ShortfallFee)`, which **may go past `CreditLimit`**, and it emits `AutoBorrowed(shortfall, fee)`.
  - `interest()` = `roundi(debt × MonthlyInterestRate)`
  - there is no bankruptcy
- **The one writer is named `_write`, not `_set`.** The spec calls it `_set`, but `Object._set(property, value)` is a Godot virtual, and a `_set` with another signature fails to parse.
- **Upkeep.** The Sheet column `upkeepK` is dollars per month in thousands and may be fractional. `BuildingInfo.DollarsPerK` = 1000 converts it in the constructor and nowhere else. A blank or missing cell reads as 0.
  - Only **open** buildings cost upkeep.
  - Every month start: first `Campus.startMonth` opens what's due, then `finances.charge(campus.upkeep() + finances.interest())`.
  - The controller added the `upkeepK` column to the Sheet on 2026-09-22: admissions 90, dorm 150, engineering_1 210, dining_1 220. The export in Task 3 brings it into `data/buildings.txt`.
- **Save format.**
  - `university` { `name`, `finances` { `cash`, `debt` }, `campus` { `month`, `buildings` } }
  - `campus` no longer has `money`
  - every `fromDict` checks its keys with `Variants.hasKeys` against a `SavedKeys` const that matches its `toDict`, and returns null (refuses) on a missing key
  - a parent refuses when a child refuses
  - `University.fromDict` builds the loaded `Finances` first and passes it to `Campus.fromDict`, so the loaded campus spends from the loaded finances
- **Removed:** `Campus.StartingMoney`, `Campus.money`, `Campus.setMoney` and `Campus.MoneyChanged`. A blank `Finances.new()` holds 0 cash and 0 debt. A new game's cash and debt come from `res://data/start_state.json`.
- **`university/data/start_state.json`** is hand-authored and in git. Task 2 edits it, with the user's standing go-ahead.
- **`university/data/buildings.txt`** is only ever written by `python3 bin/GetDataFromGoogleSheets.py`.
- **Never guess a Godot or addon API.** Grep this repo or the addon source under `university/addons/`.

const Borrowed: int = 2000000

	assert_int(finances.cash).is_equal(Cash - Bill)
	assert_int(finances.debt).is_equal(0)
	assert_array(borrowed).is_empty()

	var finances: Finances = _finances(Bill, 0)

	assert_int(finances.cash).is_equal(0)
	assert_int(finances.debt).is_equal(shortfall + fee)
	assert_array(announced).contains_exactly([shortfall, fee])

	var finances: Finances = _finances(0, Finances.CreditLimit)
	finances.charge(Bill)
	assert_int(finances.debt).is_greater(Finances.CreditLimit)
	assert_int(finances.cash).is_equal(0)

	assert_int(finances.debt).is_equal(Finances.CreditLimit)
	assert_int(finances.cash).is_equal(Finances.CreditLimit)
	assert_int(finances.borrow(Borrowed)).is_equal(0)
	assert_int(finances.availableCredit()).is_equal(0)

	var finances: Finances = _finances(Cash, Borrowed)
	# Owes more than it holds: repays only what it holds.
	assert_int(finances.repay(Borrowed)).is_equal(Cash)

	assert_int(finances.debt).is_equal(Borrowed - Cash)

	finances.setCash(Borrowed * 2)
	assert_int(finances.repay(Borrowed * 2)).is_equal(Borrowed - Cash)
	assert_int(finances.debt).is_equal(0)

	assert_float(Finances.MonthlyInterestRate * GameCalendar.MonthsPerYear).is_equal_approx(Finances.AnnualInterestRate, 0.000001)
	assert_int(_finances(Cash, 0).interest()).is_equal(0)

	finances.refund(Bill)
	finances.borrow(Borrowed)
	finances.repay(Borrowed)

- [ ] **Step 3: Write `Finances`**

Create `university/src/state/finances.gd`:

```gdscript
class_name Finances
## The university's money: cash in hand and what it owes on its credit line,
## both whole dollars and never negative. `_write` is the one writer, so no
## balance changes unannounced. Building spends cash only: to build past the
## cash the player borrows first, up to CreditLimit. The monthly bill is the one
## exception to the limit: a bill the cash cannot cover borrows the shortfall
## automatically, plus a fee, however much is already owed. There is no
## bankruptcy.

signal MoneyChanged
## A monthly bill was more than the cash; the shortfall and the fee went on the
## credit line.
signal AutoBorrowed(shortfall: int, fee: int)

# Whole dollars the player may borrow in all. The automatic draw may go past it.
const CreditLimit: int = 50000000
const AnnualInterestRate: float = 0.06
# Charged each month on what is owed: the one place a year's rate becomes a month's.
const MonthlyInterestRate: float = AnnualInterestRate / GameCalendar.MonthsPerYear
# The cost of an automatic draw, as a fraction of the shortfall it covers.
const ShortfallFee: float = 0.05
# Whole dollars one Borrow or Repay button moves.
const LoanStep: int = 5000000
# Keys toDict writes; fromDict refuses a dictionary missing any of them.
const SavedKeys: Array[String] = ["cash", "debt"]

var cash: int = 0
var debt: int = 0


func canAfford(amount: int) -> bool:
	return amount <= cash


## What building costs. Callers check canAfford first: cash never goes negative.
func spend(amount: int) -> void:
	_write(cash - amount, debt)


## What destroying a building still under construction gives back.
func refund(amount: int) -> void:
	_write(cash + amount, debt)


## What may still be borrowed before the credit limit.
func availableCredit() -> int:
	return maxi(CreditLimit - debt, 0)


## Draws up to amount on the credit line, never past the limit. Returns what it took.
func borrow(amount: int) -> int:
	var taken: int = clampi(amount, 0, availableCredit())
	_write(cash + taken, debt + taken)
	return taken


## Pays back up to amount, never more than is owed or than the cash in hand.
## Returns what it paid.
func repay(amount: int) -> int:
	var paid: int = clampi(amount, 0, mini(debt, cash))
	_write(cash - paid, debt - paid)
	return paid


## The monthly bill. Paid from cash when the cash covers it; otherwise the cash
## goes to zero and the shortfall, plus ShortfallFee of it, is borrowed
## automatically, past the credit limit if need be.
func charge(amount: int) -> void:
	if (amount <= cash):
		_write(cash - amount, debt)
		return
	var shortfall: int = amount - cash
	var fee: int = roundi(float(shortfall) * ShortfallFee)
	_write(0, debt + shortfall + fee)
	AutoBorrowed.emit(shortfall, fee)


## A month's interest on what is owed, whole dollars.
func interest() -> int:
	return roundi(float(debt) * MonthlyInterestRate)


## Sets the cash directly, for the console and tests. Never negative.
func setCash(amount: int) -> void:
	_write(maxi(amount, 0), debt)


## Sets the debt directly, for the console and tests. Never negative.
func setDebt(amount: int) -> void:
	_write(cash, maxi(amount, 0))


# The one place cash and debt are written, so every change is announced.
# Not `_set`: that name is Object's property-setting virtual.
func _write(newCash: int, newDebt: int) -> void:
	cash = newCash
	debt = newDebt
	MoneyChanged.emit()


func toDict() -> Dictionary:
	return {"cash": cash, "debt": debt}


## Null when data is missing a key.
static func fromDict(data: Dictionary) -> Finances:
	if (not Variants.hasKeys(data, SavedKeys, "Finances")):
		return null
	var finances: Finances = Finances.new()
	finances._write(Variants.toInt(data["cash"]), Variants.toInt(data["debt"]))
	return finances
```
